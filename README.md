# Day-4_Assessment-React-js-Class
A React feedback form with star rating and optimistic UI state updates.


A simple Feedback Board built with React + TypeScript + Vite.

Features:
- Submit feedback with name, message, and star rating
- Optimistic UI — feedback appears instantly before server confirms
- Feedback list updates in real time
- Built using useState and simulated server actions

Tech Stack: React, TypeScript, Vite, CSS
